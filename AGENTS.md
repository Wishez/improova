# AGENTS.md

Правила проекта для людей и агентов. Перекрывают общие.

## Команды

- `npm ci` — установка (Node ≥ 22.22.3).
- `npm test -- --watch=false` — модульные тесты (Vitest). Должны проходить перед коммитом.
- `npx ng build` — сборка; предупреждения бюджета не игнорировать.
- `npm run build:pages` — сборка с `base-href /improova/`.

## Архитектура

- Только фронтенд, без сервера (ADR-001). Хранилище — через `IStorageAdapter` и токен `STORAGE_ADAPTER` (ADR-002). Прямых обращений к IndexedDB вне `storage/` нет.
- Доменная логика (`domain/`) — чистые функции без Angular. Сервисы вызывают домен и пишут через `DataStore`.
- План недели вычисляется (ADR-003). Хранятся только закреплённые и пропущенные блоки.
- Календарь, художник недели, квартальные веса и контрольные в плане тоже вычисляются (ADR-004). Из хранимого — только `meta.dayPlans`, `routeBlocks`, `item.guide`, `item.checkpointDay`.
- Схема данных меняется только добавлением полей: новое поле получает значение по умолчанию в `normalizeCollections` (`storage/snapshot.ts`), `SCHEMA_VERSION` растёт.
- Стартовая программа (`seed/`) проверяется тестом `course.spec.ts`: у каждого топика корректный ориентир, ссылки только на легальные источники (`seed/course-links.ts`).
- Курс версионируется (ADR-005). Любое изменение содержания `seed/` — `COURSE_VERSION` +1 и запись в `COURSE_RELEASES` («Что нового»). Ключ курса не меняется: переименовал раздел, тему, топик или блок — задай `key` со старым путём. Убрал сущность — её ключ в `removedKeys` версии, ключ не переиспользуется.
- Стартовое и своё различаются `courseKey`: всё, что создаёт пользователь или импорт программы, получает `courseKey: null`. Удаление стартовой сущности записывает ключ в `meta.dismissedCourseKeys`.
- Изменения нескольких коллекций, которые должны пройти вместе, пишутся через `DataStore.commit` одной транзакцией.
- Даты — ключи дня `YYYY-MM-DD` с границей дня (`settings.dayBoundaryHour`, по умолчанию 04:00). `new Date().toISOString().slice(0, 10)` для дня не использовать — только `toDayKey`.
- Импорт — недоверенная граница: только через `checkSnapshot`, без приведений типов.
- Маршрутизация — hash (`/#/today`), чтобы GitHub Pages отдавал любой экран без 404.

## Код

- Типы с префиксами `I`, `T`; `any`, `as`, `!` для обхода проверки запрещены.
- Экспорт через `index.ts` в каждой папке слоя.
- Стили: Tailwind через `@apply`, значения только из `src/styles/theme.css`. SCSS до двух уровней, BEM с camelCase.
- Taiga-компоненты форм (checkbox, switch) подключать с `[ngModel]`/`(ngModelChange)` — без NgControl они рендерятся недоступными.
- Акцентный цвет — только у главного действия экрана и прогресса.
- Анимации учитывают `prefers-reduced-motion` (глобально в `styles/_base.scss`).

## Коммиты

Формат: `FR-<номер> <что реализовано>`; инфраструктура — `NFR <что>`, документация — `docs: <что>`.
Планы, черновики, отчёты, скриншоты и логи не коммитятся.
