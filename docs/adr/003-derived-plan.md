# ADR-003. План недели вычисляется, храним только решения пользователя

Статус: принято · 2026-09

## Контекст

План зависит от бюджета, ёмкости дней, прогресса, логов и сроков повторений. Любое изменение этих данных должно сразу менять план.

## Варианты

1. Генерировать план и сохранять все блоки; пересобирать по событиям.
2. Вычислять план детерминированно из данных; хранить только закреплённые (перенос, «закрепить») и пропущенные блоки.

## Решение

Вариант 2 (`domain/planner.ts`). Горизонт 7 дней, распределение по дефициту с весом раздела, чередование типов, повторения 3/10/30 дней. Пропуск не удваивает следующий день — время возвращается в очередь.

## Цена отказа от 1

План нельзя «заморозить» целиком — только закреплять отдельные блоки. Расчёт на каждое изменение: проверено тестом производительности (< 1,5 с на год данных).
