# ADR-001. MVP без сервера

Статус: принято · 2026-09

## Контекст

Один пользователь, данные личные, объём мал (годовая программа, логи, заметки с фото). ТЗ требует работу без регистрации и REST-адаптер после MVP (T12).

## Варианты

| Критерий | A. SPA + IndexedDB, GitHub Pages | B. SPA + API + БД |
|---|---|---|
| Время до релиза | дни | недели (API, авторизация, хостинг) |
| Стоимость | 0 | сервер и БД |
| Офлайн | есть | нужен кэш |
| Синхронизация устройств | экспорт/импорт JSON | есть |
| Риски | очистка данных браузером | доступность сервера, утечки |

## Решение

A. Хранилище за интерфейсом `IStorageAdapter`, поэтому переход на B — новая реализация адаптера без изменения сервисов.

## Цена отказа от B

Нет синхронизации между устройствами. Компенсация: экспорт JSON, напоминание о бэкапе, `navigator.storage.persist()`.
